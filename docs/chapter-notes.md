# 執筆メモ（章ごとの構成ノート）

このファイルはビルド対象（`vivliostyle.config.js`の`manuscript`配列）に含まれない、
執筆者・AIエージェント向けの作業メモです。

以前は各章の`manuscript/*.md`末尾にHTMLコメント（`<!-- ... -->`）として同じ内容を
埋め込んでいましたが、VFM（Vivliostyle Flavored Markdown）は行頭から始まる複数行の
HTMLコメントブロックを確実には無視してくれず、コメント内部が通常のMarkdownとして
解釈されて本文に漏れ出る不具合が判明した（Issue #5）。単一行のインラインHTMLコメント
（例: 見出しタグの直後に1行で書く`<!-- TODO: ... -->`）は正しく非表示になることを確認したが、
複数行のブロックは信頼できないため、このような構成メモ・TODOは今後**すべてこの外部ファイルに
集約する**運用にする。`manuscript/*.md`側にはコメントを残さない。

## 目次の暫定事項

- 幕間の挿入位置（第4章と第5章の間、第8章と第9章の間）は暫定。確定済みの目次に合わせて
  `vivliostyle.config.js`の`manuscript`配列の並び順を調整する。
- 各章タイトルは仮題のプレースホルダ。確定済みの目次に合わせて差し替える。
- `90-license.md`: リポジトリURLが確定したら、末尾に相談先リンクを追記する。
- `99-colophon.md`: タイトル・発行日・版数が確定したら、書誌情報を差し替える。

## 序章

- 伏線回収: 序章は本書全体の「伏線」を仕込む章。ここで提示したキーワード・問いを、
  どの章でどう回収する予定かを執筆時にメモしておくと、あとで一覧化しやすい。

## 第1章〜第12章（共通の観点）

各章の執筆時は、章末に以下を検討する。

- **クラウドTips**: 本章の内容に関連するクラウドサービスの小ネタコラムを1本配置する（仮）。
  例）本章で扱う概念が、AWS/Azure/GCP等のどのサービス・機能に相当するかを紹介する。
- **伏線回収**: これまでの章（序章〜本章の1つ前）で触れた要素のうち、本章で回収するものが
  あれば記載する（該当なしなら省略可）。

## 幕間1・幕間2

- クラウドTips: 幕間らしい軽めの切り口でクラウド関連の小ネタを1本挟んでもよい（任意）。
- 伏線回収: 幕間は伏線の「匂わせ」を行う場としても使える（回収は本編側で行う想定）。

## 終章

- 伏線回収: 序章〜第12章・幕間で仕込んだ伏線のうち、未回収のものが残っていないか
  最終確認する（一覧化しておくと執筆時に便利）。
- クラウドTips: 総括的なTips、または本書全体を通じたクラウド関連の学習ロードマップを
  紹介するコラムをここに配置してもよい（仮）。
