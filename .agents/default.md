# default — 通常作業を行うエージェントの方針

このリポジトリで原稿執筆・設定変更・CI修正などの通常作業を行うエージェント（Claude Codeのメインセッション
を含む）全般に適用する方針。

## 実行モード

- **基本的にオートモードで実行する。** 逐一の確認は求めず、明らかな判断で進めてよい。ただし、
  destructiveな操作（force push、履歴の書き換え、ファイルの大量削除等）や、著者の意図確認が必要な
  内容判断（章タイトルの確定、目次構成の変更など）は、通常のClaude Codeの安全方針どおり確認を挟む。

## サブエージェントの利用

- サブエージェント（Agent tool）の利用を許可する。多くの作業は単一セッションで完結するため
  「たぶん使う機会は多くない」想定だが、禁止はしない。
- 明確に用途が定まっているのはレビュー工程（[`review.md`](./review.md)参照）。それ以外でも、
  独立した調査・並行作業に有効だと判断した場合は使ってよい。

## モデルの使い分け

- 通常作業はセッションのデフォルトモデルでよい。
- **重い作業・重要な作業（例: 大規模なリファクタ、原稿全体に関わる構成変更、最終的な仕上げ作業など）
  では Fable 5 (`claude-fable-5`) の使用を許可する。** コストより品質・一貫性を優先してよい場面という
  判断基準。
- レビュー工程のモデル使い分けは [`review.md`](./review.md) を参照。
