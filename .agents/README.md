# .agents/ — エージェント運用ルール

このディレクトリは、このリポジトリでAIエージェント（Claude Code等）に作業してもらう際の運用方針を
まとめたものです。実行の都度これを読み込ませる想定ではなく、`CLAUDE.md`から参照される
「詳細ルールブック」という位置づけです。

- [`default.md`](./default.md): 通常の作業（原稿執筆、設定変更など）を行うエージェント全般の方針
- [`review.md`](./review.md): レビュー工程の方針（レビュー専用サブエージェントの使い方、モデルの使い分け）

実際にClaude Codeから呼び出し可能な「レビュー専用サブエージェント」の定義本体は
[`.claude/agents/reviewer.md`](../.claude/agents/reviewer.md) にあります。`.agents/review.md` は
そのサブエージェントを**どう運用するか**（いつ・どのモデルで呼ぶか）のルールを定義し、
`.claude/agents/reviewer.md` は**そのサブエージェント自体の振る舞い**を定義する、という役割分担です。
